# Carpeta de Imágenes

Esta carpeta debe contener las fotos del evento en formato WebP.

## Instrucciones:

1. Coloca todas las fotos del evento aquí
2. Si las fotos están en otro formato (JPG, PNG), usa el script `convertir_a_webp.py` para convertirlas
3. Ejecuta `python generar_lista_fotos.py` para actualizar el selector
4. Abre `selector.html` para comenzar a clasificar las fotos

## Nota:
Las imágenes NO se suben a GitHub debido a su tamaño. Solo se sube el código del selector.
